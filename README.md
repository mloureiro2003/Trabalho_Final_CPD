Esse reposítorio contém diversos arquivos relacionados ao trabalho, sendo eles:
1. "MariaLoureiro_Relatorio.pdf" - Relatorio do trabalho, 
detalhando a utilidade do programa, estruturas de dados e funções utilizados e processo em geral;
2. "Monsters_D&D5e.cvs" - Versão adaptada dessa planilha do Excel (https://docs.google.com/spreadsheets/d/16ajgJpvUI0wYcSU7kjHutw8oB6Zv6eIAo5JtI6PLvu8/edit?gid=776794522#gid=776794522)
que serve para inserir os dados no programa;
3. "executavel.exe" - Executável do código em "main.py" que permite ao usuário filtrar os monstros de D&D 5ª edição presentes na planilha
acima e inserir novos monstros a um arquivo texto que age como um banco de dados para o programa;  
4. "main.py" - código fonte do programa, contém documentação detalhada de todas as funções;
5. "monsters.py" - arquivo que contém as estruturas de dados utilizadas para guardar os dados dos monstros durante a aplicação;
6. "trees.py" - arquivo que contém as árvores utilizadas para guardar os monstros durante a aplicação;
